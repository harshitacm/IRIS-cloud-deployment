# CLOUD-BASED MACHINE LEARNING MODEL DEPLOYMENT

## Project Title
Iris Flower Classification

## Project Description
This project is a real machine learning application that uses the Iris dataset, trains a Random Forest classifier, saves the trained model, and deploys it as a Streamlit web application. The application predicts the flower species based on sepal and petal measurements.

## Features
- Loads the Iris dataset from scikit-learn
- Preprocesses and splits the data
- Trains a Random Forest Classifier
- Evaluates the model using accuracy and classification report
- Saves the trained model as iris_model.pkl
- Exposes a user-friendly Streamlit interface for predictions
- Ready for deployment on Streamlit Community Cloud

## Technologies Used
- Python
- Streamlit
- pandas
- NumPy
- scikit-learn
- pickle

## Install Dependencies
```bash
pip install -r requirements.txt
```

## Train the Model
```bash
python train_model.py
```

## Run the Streamlit Application
```bash
streamlit run app.py
```

## Deploy to Streamlit Community Cloud
1. Push this project to a GitHub repository.
2. Open Streamlit Community Cloud.
3. Select the repository and branch.
4. Set the main application file to app.py.
5. Deploy the app.

The project does not require environment variables, external APIs, or a database.

## Notes
The model file iris_model.pkl is generated by train_model.py and is required by app.py for prediction.
